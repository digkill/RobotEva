1. КОМАНДА "STOP"
   • Робот замолкает
   • Не инициирует разговоры (idle_chat)
   • Игнорирует обычные команды
   • Отображает грустную эмоцию
   • Говорит: "Хорошо, молчу"
   • Wake word продолжает работать

2. КОМАНДА "ДАВАЙ ПОГОВОРИМ"
   • Робот снова активен
   • Возобновляет разговоры
   • Отвечает на команды
   • Отображает радостную эмоцию
   • Говорит: "Да, давай поговорим!"

Откройте config.yaml:

behavior:
  activity_control:
    enabled: true
    stop_commands:
      - "stop"
      - "стоп"
      # Добавьте свои команды
    resume_commands:
      - "давай поговорим"
      - "поговорим"
      # Добавьте свои команды
    stop_response: "Хорошо, молчу"
    resume_response: "Да, давай поговорим!"

🧪 ТЕСТИРОВАНИЕ
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Запустите робота:
   python3 main.py

2. Активируйте wake word:
   Скажите: "Alexa"

3. Дайте команду Stop:
   Скажите: "Стоп"
   Ожидается: "Хорошо, молчу" (грустная эмоция)

4. Попробуйте обычную команду:
   Скажите: "Alexa" → "Какая погода?"
   Ожидается: молчание (команда проигнорирована)

5. Дайте команду Resume:
   Скажите: "Alexa" → "Давай поговорим"
   Ожидается: "Да, давай поговорим!" (радостная эмоция)

6. Проверьте обычную работу:
   Скажите: "Alexa" → "Какая погода?"
   Ожидается: нормальный ответ

📊 ТЕХНИЧЕСКИЕ ДЕТАЛИ
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Флаг активности:
  self._is_active: bool = True

Методы:
  set_active(is_active: bool) - установить активность
  is_active() -> bool - проверить активность

Логика:
  1. Команды Stop/Resume обрабатываются ДО LLM
  2. Если робот неактивен, обычные команды игнорируются
  3. Stop/Resume команды работают ВСЕГДА
  4. idle_chat проверяет флаг перед инициацией
