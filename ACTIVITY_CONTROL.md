# Команды управления активностью RobotEva

## 🎯 Описание функционала

Добавлена возможность управлять активностью робота с помощью голосовых команд:
- **Stop** - робот замолкает и перестаёт сам инициировать разговор
- **Давай поговорим** - робот снова начинает разговаривать

## ✨ Возможности

### Команда "Stop" (остановка)
Когда вы говорите команду остановки, робот:
- ✅ Перестаёт отвечать на обычные запросы
- ✅ Не инициирует idle_chat (автоматические разговоры)
- ✅ Отображает грустную эмоцию
- ✅ Говорит фразу подтверждения ("Хорошо, молчу")
- ✅ Продолжает слушать wake word
- ✅ Продолжает отслеживать лица (face tracking)
- ✅ Реагирует только на команды Stop/Resume

### Команда "Resume" (возобновление)
Когда вы говорите команду возобновления, робот:
- ✅ Снова начинает отвечать на запросы
- ✅ Возобновляет idle_chat
- ✅ Отображает радостную эмоцию
- ✅ Говорит фразу подтверждения ("Да, давай поговорим!")
- ✅ Работает в обычном режиме

## 🎤 Поддерживаемые команды

### Команды остановки (Stop):
- "stop"
- "стоп"
- "замолчи"
- "молчать"
- "тихо"
- "заткнись"

### Команды возобновления (Resume):
- "давай поговорим"
- "поговорим"
- "resume"
- "продолжай"
- "начинай"
- "говори"

## ⚙️ Настройка в config.yaml

```yaml
behavior:
  # Управление активностью (Stop/Resume команды)
  activity_control:
    enabled: true  # Включить/выключить функционал
    
    # Команды для остановки
    stop_commands:
      - "stop"
      - "стоп"
      - "замолчи"
      - "молчать"
      - "тихо"
      - "заткнись"
    
    # Команды для возобновления
    resume_commands:
      - "давай поговорим"
      - "поговорим"
      - "resume"
      - "продолжай"
      - "начинай"
      - "говори"
    
    # Фразы ответа
    stop_response: "Хорошо, молчу"
    resume_response: "Да, давай поговорим!"
```

## 🔧 Технические детали

### Изменения в коде

#### 1. robot_eva/core/robot.py

**Добавлен флаг активности:**
```python
self._is_active = True  # Флаг активности: False = робот молчит
```

**Добавлены методы:**
```python
def set_active(self, is_active: bool) -> None:
    """Установить активность робота (Stop/Resume)"""
    
def is_active(self) -> bool:
    """Проверить активность робота"""
```

**Проверка команд в `_process_command_impl`:**
- Перед обработкой через LLM проверяются stop/resume команды
- Если робот неактивен, обычные команды игнорируются
- Stop/Resume команды работают всегда

**Модификация `_idle_chat_loop`:**
- Проверка флага `_is_active` перед инициацией разговора
- Если робот неактивен, idle chat не запускается

#### 2. config.yaml

Добавлена новая секция `behavior.activity_control` с:
- Флагом включения/выключения
- Списком команд остановки
- Списком команд возобновления
- Настраиваемыми фразами ответа

## 🎨 Кастомизация

### Добавить свои команды

Отредактируйте `config.yaml`:

```yaml
behavior:
  activity_control:
    stop_commands:
      - "stop"
      - "стоп"
      - "отдохни"  # ← Ваша команда
      - "пауза"     # ← Ваша команда
    
    resume_commands:
      - "давай поговорим"
      - "вернись"   # ← Ваша команда
      - "продолжим" # ← Ваша команда
```

### Изменить фразы ответа

```yaml
behavior:
  activity_control:
    stop_response: "Я помолчу, позови если понадоблюсь"
    resume_response: "С радостью! Что будем делать?"
```

### Отключить функционал

```yaml
behavior:
  activity_control:
    enabled: false  # Функционал отключен
```

## 🔍 Логирование

При использовании команд в логах появляются записи:

```
[INFO] Heard (STT): стоп
[INFO] Команда STOP получена - робот остановлен
[INFO] Робот остановлен

[INFO] Heard (STT): давай поговорим
[INFO] Команда RESUME получена - робот активирован
[INFO] Робот активен
```

Когда робот неактивен:
```
[INFO] Heard (STT): какая погода
[INFO] Робот неактивен - команда проигнорирована
```

## ⚠️ Важные замечания

1. **Wake word продолжает работать** - даже в режиме Stop вы можете активировать робота через wake word

2. **Face tracking активен** - отслеживание лиц продолжается даже в режиме Stop

3. **Только Stop/Resume работают** - в режиме Stop робот реагирует только на команды Stop и Resume

4. **Idle chat отключается** - автоматические разговоры прекращаются в режиме Stop

5. **Перезапуск сохраняет активность** - при перезапуске робот возвращается в активное состояние
