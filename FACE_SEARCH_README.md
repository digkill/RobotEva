# Поиск по лицам (Face Search) 🤖🔍

## Обзор

RobotEva теперь поддерживает поиск по лицам в интернете для поиска информации о людях на основе их внешности. Эта функция использует компьютерное зрение для описания внешности человека и последующего поиска в интернете.

## ⚠️ Важные предупреждения по приватности

**ЭТА ФУНКЦИЯ КАСАЕТСЯ ПРИВАТНОСТИ ЛЮДЕЙ!**

- **Никогда не используйте без согласия**: Не выполняйте поиск по лицам незнакомых людей без их явного согласия
- **Этические ограничения**: Функция предназначена только для поиска публично доступной информации
- **Юридические аспекты**: Убедитесь, что использование соответствует законам о приватности в вашей стране
- **Ответственное использование**: Используйте только для полезных целей (поиск пропавших людей, идентификация публичных фигур и т.д.)

## Как использовать

### Через голосовые команды

Скажите роботу одну из следующих фраз:
- "Найди информацию об этом человеке"
- "Кто этот человек на фото?"
- "Поищи данные о человеке с камеры"
- "Распознай лицо и найди информацию"

### Через действия LLM

LLM может автоматически вызывать поиск по лицам, когда распознает соответствующую команду.

## Техническая реализация

### Алгоритм работы

1. **Захват изображения**: Робот делает фото с камеры
2. **Анализ лица**: Vision API (GPT-4o-mini) описывает внешность человека
3. **Поиск в интернете**: По текстовому описанию ищется информация
4. **Результаты**: Возвращаются найденные данные с предупреждением о приватности

### Поддерживаемые поисковые системы

- **Google** (по умолчанию) - наиболее точные результаты
- **Yandex** - хорошая альтернатива для русскоязычного поиска
- **Bing** - дополнительная опция

### Параметры поиска

```json
{
  "type": "face_search",
  "search_engine": "google",  // "google", "yandex", "bing"
  "max_results": 5
}
```

## Примеры использования

### Пример 1: Поиск знаменитости
```
Пользователь: "Кто этот человек на экране?"
Робот: "Вижу человека средних лет с бородой. Ищу информацию..."
Результат: "Это может быть [Имя], [описание]..."
```

### Пример 2: Поиск в социальных сетях
```
Пользователь: "Найди этого человека в соцсетях"
Робот: "⚠️ Поиск по лицам может затрагивать приватность. Продолжить?"
```

## Конфигурация

Добавьте в `config.yaml`:

```yaml
ai:
  vision:
    model: gpt-4o-mini  # Для описания лиц
    max_tokens: 300

services:
  internet:
    search_engine: google  # Основная поисковая система
```

## Ограничения

- **Точность**: Результаты зависят от качества описания лица Vision API
- **Приватность**: Никаких прямых API для распознавания лиц (Face++ и т.д.)
- **Этика**: Встроенные предупреждения и ограничения
- **Производительность**: Поиск занимает 10-30 секунд

## Безопасность

- Все поиски логируются
- Добавляются предупреждения о приватности
- Требуется явное согласие пользователя
- Используется только публичные поисковые системы
