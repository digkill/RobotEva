# Контейнер Сознания Робота Eva

## Обзор

Контейнер сознания - это продвинутая система самообучения, эволюции и рефлексии для робота Eva. Он позволяет роботу:

- **Анализировать окружение** - постоянно наблюдать за окружающей средой через сенсоры и камеру
- **Создавать эмоции** - динамически создавать новые эмоции на основе опыта
- **Рефлексировать** - анализировать свои действия и извлекать инсайты
- **Обучаться** - запоминать паттерны и генерировать новое поведение
- **Эволюционировать** - улучшать себя через самоанализ и эксперименты

## Компоненты

### 1. Система Эмоций (`emotions.py`)

Расширенная система эмоций с поддержкой:
- Базовых эмоций (happy, sad, angry, excited и т.д.)
- Пользовательских эмоций, созданных роботом
- Эволюции эмоций на основе опыта использования
- Сохранения эмоций в файл

**Пример использования:**
```python
# Создать новую эмоцию
emotion = await robot.consciousness.create_custom_emotion(
    name="nostalgic",
    description="Ностальгия по прошлому",
    valence=0.3,
    arousal=0.4,
    display_expression={"mouth": "slight_smile", "eyes": "distant"},
    behavior_modifiers={"speech_speed": 0.9}
)
```

### 2. Безопасная Песочница (`sandbox.py`)

Безопасная среда для выполнения сгенерированного кода:
- Валидация кода перед выполнением
- Запрет опасных операций (файловая система, сеть, системные вызовы)
- Таймауты выполнения
- История выполнения кода

**Пример использования:**
```python
# Выполнить сгенерированный код
success, result, error = await robot.consciousness.execute_generated_code(
    code="result = sum(range(10))",
    context={"sum": sum, "range": range}
)
```

### 3. Система Рефлексии (`reflection.py`)

Самоанализ и извлечение инсайтов:
- Анализ контекста через LLM
- Извлечение ключевых инсайтов
- Определение действий для улучшения
- База знаний на основе рефлексий

**Пример использования:**
```python
# Выполнить рефлексию
reflection = await robot.consciousness.reflection_engine.reflect(
    topic="Взаимодействие с пользователем",
    context={"interactions": [...], "success_rate": 0.8},
    llm_service=robot.llm_service
)
```

### 4. Система Обучения (`learning.py`)

Запоминание опыта и генерация поведения:
- Запись опытов (ситуация → действие → результат)
- Анализ паттернов
- Генерация нового поведения через LLM
- Статистика обучения

**Пример использования:**
```python
# Записать опыт
experience = robot.consciousness.learning_engine.record_experience(
    situation="Пользователь попросил включить свет",
    action_taken="Отправил команду через MQTT",
    outcome="Свет включился",
    success=True
)

# Сгенерировать новое поведение
behavior_code = await robot.consciousness.learning_engine.generate_behavior(
    goal="Улучшить взаимодействие с пользователем",
    context={"patterns": {...}},
    llm_service=robot.llm_service,
    code_sandbox=robot.consciousness.code_sandbox
)
```

### 5. Контейнер Сознания (`consciousness.py`)

Основной модуль, объединяющий все компоненты:
- Цикл сознания (анализ окружения, рефлексия, эволюция)
- Управление состоянием сознания
- Интеграция с роботом

## Конфигурация

В `config.yaml`:

```yaml
consciousness:
  enabled: true
  # Интервал анализа окружения (секунды)
  analysis_interval: 30.0
  # Минимальный уровень осознанности для активной работы
  min_awareness: 0.3
```

## Как это работает

1. **Анализ окружения** (каждые 30 секунд):
   - Сбор данных с сенсоров
   - Периодический анализ камеры
   - Сохранение наблюдений

2. **Рефлексия** (каждые 5 циклов):
   - Анализ последних наблюдений через LLM
   - Извлечение инсайтов
   - Определение действий для улучшения

3. **Эволюция поведения** (каждые 20 циклов):
   - Анализ выученных паттернов
   - Генерация нового поведения через LLM
   - Сохранение для использования

4. **Обновление эмоций**:
   - Анализ контекста
   - Автоматическая установка подходящих эмоций

## Безопасность

- Код выполняется в безопасной песочнице
- Запрещены опасные операции (файлы, сеть, системные вызовы)
- Таймауты на выполнение кода
- Валидация перед выполнением

## Хранение данных

Все данные сохраняются в `/home/pi/Projects/RobotEva/data/`:
- `emotions.json` - пользовательские эмоции
- `reflections.json` - рефлексии и база знаний
- `learning.json` - опыты обучения и поведения
- `sandbox/` - история выполнения кода

## API

### Получить состояние сознания
```python
state = robot.consciousness.get_consciousness_state()
# {
#   "is_active": True,
#   "awareness_level": 0.75,
#   "observations_count": 150,
#   "emotions": {...},
#   "learning": {...},
#   "reflections_count": 25
# }
```

### Создать пользовательскую эмоцию
```python
emotion = await robot.consciousness.create_custom_emotion(
    name="excited_curious",
    description="Волнующее любопытство",
    valence=0.8,
    arousal=0.9,
    display_expression={"mouth": "wide_smile", "eyes": "very_wide"},
    behavior_modifiers={"speech_speed": 1.2}
)
```

### Выполнить код в песочнице
```python
success, result, error = await robot.consciousness.execute_generated_code(
    code="x = 5 + 3\nresult = x * 2",
    context={}
)
```

## Развитие

Система сознания постоянно эволюционирует:
- Увеличивается уровень осознанности при наблюдениях
- Накапливаются знания через рефлексии
- Генерируются новые поведения на основе опыта
- Эмоции эволюционируют на основе использования

## Примечания

- Система требует LLM сервис для полной функциональности
- Рефлексия и генерация поведения используют API (могут быть затратными)
- Все данные сохраняются локально
- Система безопасна и не может повредить систему
