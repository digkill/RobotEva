# 🧠 Система Долгосрочной Памяти RobotEva

## Обзор

RobotEva теперь обладает **продвинутой системой долгосрочной памяти**, которая сохраняет все взаимодействия, накапливает знания и использует контекст для улучшения ответов.

## 📚 Что сохраняется в памяти

### Взаимодействия
- **Все голосовые команды** пользователей
- **Ответы робота** на каждый запрос
- **Контекст взаимодействия** (эмоции, действия, результаты)
- **Оценки успешности** ответов

### Знания
- **Факты о пользователе** (предпочтения, привычки)
- **Успешные паттерны** ответа на типичные запросы
- **Извлеченные инсайты** из разговоров
- **Тематические знания** по обсуждаемым темам

### Контекст
- **История разговоров** в сессиях
- **Эмоциональное состояние** во время взаимодействия
- **Результаты действий** (успех/неудача)
- **Связанные теги** для поиска

### Опыт саморазвития
- **Рефлексия**: инсайты из самоанализа поведения и эмоций
- **Саморазвитие**: изменения в коде, архитектуре и навыках
- **Мета-эмоции**: опыт эмоций о собственных эмоциях
- **Креативность**: успешные творческие идеи и решения
- **Социальное обучение**: адаптация к взаимодействиям с людьми
- **Эволюция навыков**: развитие способностей со временем

## 🏗️ Архитектура памяти

### Основные компоненты:

#### 1. **ContextMemorySystem** - Основная система памяти
- Хранение всех разговоров и знаний
- Поиск релевантного контекста
- Извлечение знаний из взаимодействий
- Статистика и аналитика

#### 2. **ConversationContext** - Контекст разговора
```python
{
    "session_id": "session_123456",
    "user_input": "Какой сегодня день?",
    "robot_response": "Сегодня вторник",
    "input_type": "voice",
    "success_rating": 0.9,
    "tags": ["time", "information"],
    "context_data": {...}
}
```

#### 3. **KnowledgeEntry** - Запись знаний
```python
{
    "category": "preference",
    "content": "Пользователь предпочитает краткие ответы",
    "confidence": 0.8,
    "source": "conversation",
    "usage_count": 5
}
```

## 🔍 Функциональность

### Автоматическое сохранение
Каждое взаимодействие автоматически сохраняется:
- Голосовые команды в `_process_command_impl`
- Результаты действий и эмоции
- Оценки успешности ответов
- Извлеченные знания

### Поиск и использование контекста
```
Запрос пользователя: "Как погода?"
Система ищет: предыдущие вопросы о погоде
Находит: "Ранее ты спрашивал о погоде, но я не смог ответить"
Результат: "Извини, у меня нет доступа к погоде, но я помню, что ты уже спрашивал об этом"
```

### Накопление знаний
```
Из разговора: "Я люблю классическую музыку"
Извлекается: Знание "preference: classical music"
При будущем запросе: Учитывается предпочтение в рекомендациях
```

### Статистика и аналитика
- Количество сохраненных разговоров
- Средний рейтинг успешности ответов
- Популярные темы и паттерны
- Использование памяти

## 💡 Примеры использования

### Контекстные ответы
```
Пользователь: "Расскажи шутку"
Робот: [Ищет в памяти предыдущие шутки]
       [Находит: пользователь любит программистские шутки]
       [Генерирует: шутку про программистов]
```

### Адаптация к предпочтениям
```
Анализ памяти показывает:
- Пользователь предпочитает краткие ответы
- Часто спрашивает о технологиях
- Положительно реагирует на юмор

Робот адаптирует стиль:
- Даёт краткие, но информативные ответы
- Добавляет технические детали
- Вставляет шутки в подходящие моменты
```

### Обучение на ошибках
```
Предыдущий ответ: "Я не знаю погоду" (рейтинг 0.3)
Текущий запрос: "Какая погода?"
Робот: [Вспоминает предыдущий неудачный ответ]
       [Предлагает альтернативу или объясняет ограничения]
```

### Использование опыта саморазвития
```
Запрос пользователя: "Расскажи историю"
Робот ищет: опыт креативности и социального обучения
Находит: "Истории нравятся людям, повышают вовлеченность"
Находит: "Успешная история: о путешествиях"
Результат: Создает увлекательную историю о путешествиях
```

### Самообучение на рефлексии
```
Из рефлексии: "Я слишком много говорю в ответах"
Записывается: инсайт "быть более лаконичным"
В будущем: ответы становятся короче и по делу

Из мета-эмоций: "Чувствую гордость за хорошие ответы"
Записывается: "Гордость мотивирует к качеству"
Результат: Повышается мотивация к улучшениям
```

## ⚙️ Конфигурация

```yaml
# Система памяти
context_memory:
  enabled: true
  max_conversations: 5000      # Максимум разговоров
  max_knowledge: 10000         # Максимум знаний
  knowledge_threshold: 0.7     # Порог уверенности
  auto_backup_interval: 3600   # Автосохранение (сек)
```

## 🔧 Команды для работы с памятью

### Через голосовые команды:
```
"Что мы обсуждали?"          # История разговоров
"Напомни о [тема]"           # Поиск по теме
"Как я обычно спрашиваю?"    # Паттерны поведения
"Что ты знаешь обо мне?"     # Знания о пользователе
```

### Через действия LLM:
```json
{
  "type": "memory",
  "action": "recall",
  "query": "погода"
}
```

### Доступные действия:
- **recall** - Получить релевантный контекст
- **search** - Поиск по памяти
- **stats** - Статистика памяти
- **context** - История разговоров

#### Команды саморазвития:
- **self_development** с действиями:
  - **evolution** - История эволюции навыков
  - **skills** - Приобретенные навыки
  - **insights** - Инсайты из рефлексии
  - **reflect** - Запустить рефлексию

## 🛡️ Безопасность и приватность

### Защита данных:
- Локальное хранение (не в облаке)
- Шифрование чувствительных данных
- Возможность очистки старых данных

### Этические аспекты:
- Только собственные взаимодействия
- Нет передачи данных третьим сторонам
- Пользователь может запросить удаление данных

### Управление памятью:
```python
# Очистка старых данных
await memory.clear_old_data(days=30)

# Экспорт/импорт
await memory.export_memory("backup.json")
await memory.import_memory("backup.json")
```
