## How It Works / Как работает

### Технология

**Локальное распознавание через OpenCV:**
- **Haar Cascade Classifier** - быстрый алгоритм детекции лиц
- Работает полностью локально (без интернета!)
- Обрабатывает 8 кадров в секунду (настраивается)
- Определяет положение лица в кадре

### Алгоритм

1. **Захват кадра** с камеры (8 FPS)
2. **Конвертация в grayscale** для ускорения
3. **Детекция лица** через Haar Cascade
4. **Расчёт смещения** лица от центра кадра
5. **Вычисление углов** для сервоприводов (yaw/pitch)
6. **Плавное движение** головы с сглаживанием
7. **Возврат в центр** если лицо не видно 2 секунды

### Сервоприводы

- **Yaw (поворот влево/вправо):** Канал 2 (`SERVO_HEAD_YAW`)
- **Pitch (наклон вверх/вниз):** Канал 0 (`SERVO_HEAD_PITCH`)

## Configuration / Настройка

### Current Settings / Текущие настройки

В `config.yaml`:

```yaml
behavior:
  face_tracking:
    enabled: true                      # ✅ УЖЕ ВКЛЮЧЕНО!
    fps: 8                             # 8 кадров в секунду
    pause_while_speaking: false        # Работает даже когда робот говорит
    return_to_center_seconds: 2.0      # Возврат через 2 сек без лица
    
    # Детекция (чувствительность)
    scale_factor: 1.1                  # Меньше = чувствительнее (1.05-1.5)
    min_neighbors: 4                   # Меньше = чувствительнее (3-10)
    min_face_size_px: 30               # Минимальный размер лица в пикселях
    
    # Движение (диапазоны)
    max_yaw_deg: 40                    # Максимум влево/вправо (градусы)
    max_pitch_deg: 25                  # Максимум вверх/вниз (градусы)
    
    # Плавность
    smoothing_alpha: 0.75              # Сглаживание (0-1, больше = плавнее)
    deadzone: 0.07                     # Мёртвая зона в центре (0-0.3)
    smooth_steps: 8                    # Шагов интерполяции
    smooth_delay: 0.015                # Задержка между шагами (сек)
    
    # Инверсия
    invert_yaw: false                  # Инвертировать лево/право
    invert_pitch: true                 # Инвертировать верх/низ
    
    # Отладка
    debug: false                       # Детальные логи
    log_on_face_detected: true         # Лог при обнаружении лица
```

## Parameters Explanation / Объяснение параметров

### Detection / Детекция

**`fps`** - Частота обработки кадров
- Больше = быстрее реакция, больше нагрузка на CPU
- Рекомендуется: 5-10

**`scale_factor`** - Масштабирование при поиске
- Меньше (1.05-1.1) = более чувствительно, медленнее
- Больше (1.3-1.5) = менее чувствительно, быстрее
- По умолчанию: 1.1 (хороший баланс)

**`min_neighbors`** - Минимум соседних детекций
- Меньше (3-4) = находит лица дальше/в тени, больше ложных срабатываний
- Больше (7-10) = только чёткие лица, меньше ложных срабатываний
- По умолчанию: 4 (чувствительный)

**`min_face_size_px`** - Минимальный размер лица
- Меньше (20-30) = находит лица дальше
- Больше (50-100) = только близкие лица
- По умолчанию: 30

### Movement / Движение

**`max_yaw_deg`** - Максимальный поворот головы влево/вправо
- Диапазон: 1-60 градусов
- По умолчанию: 40 (широкий диапазон)

**`max_pitch_deg`** - Максимальный наклон головы вверх/вниз
- Диапазон: 1-45 градусов
- По умолчанию: 25

**`smoothing_alpha`** - Коэффициент сглаживания
- 0 = мгновенное движение (дёрганое)
- 0.95 = очень плавное (медленное)
- По умолчанию: 0.75 (хороший баланс)

**`deadzone`** - Мёртвая зона в центре
- 0 = реагирует на любое смещение
- 0.3 = игнорирует малые смещения
- По умолчанию: 0.07 (маленькая зона)

**`smooth_steps`** - Шагов интерполяции
- 1 = резкое движение
- 8 = очень плавное
- По умолчанию: 8

### Behavior / Поведение

**`pause_while_speaking`** - Пауза при разговоре
- `true` = останавливает tracking когда робот говорит
- `false` = продолжает следить всегда
- По умолчанию: false (всегда активен)

**`return_to_center_seconds`** - Возврат в центр
- 0 = не возвращается (остаётся где был)
- 2-5 = возврат через N секунд без лица
- По умолчанию: 2.0

**`invert_yaw`** / **`invert_pitch`** - Инверсия осей
- Если сервопривод двигается в неправильную сторону, измените на `true`
- По умолчанию: yaw=false, pitch=true

## Tuning / Настройка

### Робот не видит лицо

**Проблема:** `faces=0` в логах

**Решения:**
1. Увеличьте чувствительность:
   ```yaml
   scale_factor: 1.05      # Было 1.1
   min_neighbors: 3        # Было 4
   ```

2. Уменьшите минимальный размер:
   ```yaml
   min_face_size_px: 20    # Было 30
   ```

3. Улучшите освещение комнаты

### Робот дёргается

**Проблема:** Резкие движения головы

**Решения:**
1. Увеличьте сглаживание:
   ```yaml
   smoothing_alpha: 0.85   # Было 0.75
   ```

2. Увеличьте deadzone:
   ```yaml
   deadzone: 0.15          # Было 0.07
   ```

3. Больше шагов интерполяции:
   ```yaml
   smooth_steps: 12        # Было 8
   smooth_delay: 0.02      # Было 0.015
   ```

### Робот двигается в неправильную сторону

**Проблема:** Двигаюсь влево, робот поворачивает вправо

**Решение:**
```yaml
invert_yaw: true          # Инвертировать ось
```

Или для pitch:
```yaml
invert_pitch: false       # Было true
```

### Робот двигается слишком медленно

**Проблема:** Долгая реакция

**Решения:**
1. Увеличьте FPS:
   ```yaml
   fps: 12                 # Было 8
   ```

2. Уменьшите сглаживание:
   ```yaml
   smoothing_alpha: 0.5    # Было 0.75
   ```

### Робот двигается слишком далеко

**Проблема:** Голова поворачивается слишком сильно

**Решение:**
```yaml
max_yaw_deg: 25           # Было 40
max_pitch_deg: 15         # Было 25
```

## Technical Details / Технические детали

### Haar Cascade

**Файл:** `haarcascade_frontalface_default.xml`

Автоматически находится в:
```python
cv2.data.haarcascades + "haarcascade_frontalface_default.xml"
```

### Coordinate System / Система координат

**Frame coordinates:**
- (0, 0) = верхний левый угол
- (w, h) = нижний правый угол
- Центр = (w/2, h/2)

**Normalized error:**
- `ex = (cx - w/2) / (w/2)` → -1..1 (лево..право)
- `ey = (cy - h/2) / (h/2)` → -1..1 (верх..низ)

**Servo angles:**
- `yaw = yaw_center + (ex * max_yaw_deg)`
- `pitch = pitch_center + (ey * max_pitch_deg)`

### Performance / Производительность

**CPU usage:**
- 8 FPS: ~5-10% CPU (Raspberry Pi 5)
- 15 FPS: ~10-15% CPU

**Latency:**
- Детекция: ~50-100ms
- Движение сервопривода: ~100-200ms
- Общая задержка: ~150-300ms
