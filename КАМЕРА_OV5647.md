# Интеграция камеры OV5647 в RobotEva

## Что было сделано

Добавлена полная поддержка CSI камеры OV5647 (5MP) в проект RobotEva. Теперь робот может работать как с USB веб-камерами, так и с CSI камерами Raspberry Pi.

## Возможности камеры OV5647

Камера OV5647 поддерживает следующие режимы:

| Режим | Разрешение | Макс FPS | Применение |
|-------|-----------|----------|------------|
| 0 | 640x480 | 58.92 | Быстрое отслеживание движений |
| 1 | 1296x972 | 46.34 | **Рекомендуется** - баланс качества и скорости |
| 2 | 1920x1080 | 32.81 | Высокое качество видео, Full HD |
| 3 | 2592x1944 | 15.63 | Максимальное разрешение для фото |

## Изменённые файлы

### 1. `robot_eva/hardware/camera.py`
- Добавлена поддержка CSI и USB камер
- Реализован бэкенд `picamera2` для CSI камер
- Автоматическое определение типа камеры из конфигурации

### 2. `config.yaml`
```yaml
hardware:
  camera:
    type: csi              # "csi" для OV5647, "usb" для веб-камеры
    index: 0
    resolution: [1296, 972]  # Режим 1 - оптимальный баланс
    fps: 46
```

### 3. `scripts/check_camera.py`
- Добавлена поддержка проверки CSI камер
- Улучшенная диагностика и сообщения об ошибках

## Быстрый старт

### Шаг 1: Подключение камеры

1. Выключите Raspberry Pi
2. Найдите разъём CSI (между HDMI и аудио разъёмом)
3. Аккуратно поднимите чёрный зажим
4. Вставьте шлейф камеры синей стороной к аудио разъёму
5. Защёлкните зажим обратно

### Шаг 2: Включение интерфейса камеры

```bash
sudo raspi-config
# Перейдите: Interface Options -> Camera -> Yes
sudo reboot
```

### Шаг 3: Установка зависимостей

```bash
cd /home/pi/Projects/RobotEva
bash install_camera_deps.sh
```

Или установите вручную:
```bash
# Системные пакеты
sudo apt update
sudo apt install -y python3-picamera2 libcamera-apps python3-opencv

# Python пакеты
pip3 install -r requirements.txt
```

### Шаг 4: Проверка камеры

```bash
# Проверка с помощью libcamera
libcamera-hello --list-cameras

# Должен показать:
# 0 : ov5647 [2592x1944 10-bit GBRG] (/base/axi/pcie@1000120000/rp1/i2c@80000/ov5647@36)
```

```bash
# Проверка с помощью тестового скрипта
python3 test_ov5647.py

# Если всё работает, создастся файл test_ov5647_capture.jpg
```

### Шаг 5: Запуск RobotEva

```bash
python3 main.py

# В логах должно быть:
# [INFO] CSI камера инициализирована (разрешение: [1296, 972], FPS: 46)
```

## Использование камеры в коде

Камера доступна через объект робота:

```python
# Захват кадра
frame = await robot.camera.capture_frame()

# Сохранение фото
await robot.camera.save_frame("фото.jpg")

# Проверка доступности
if robot.camera.is_available():
    print("Камера готова!")
```

## Решение проблем

### Камера не обнаруживается

```bash
# Проверка обнаружения
libcamera-hello --list-cameras

# Проверка ошибок
dmesg | grep -i camera

# Проверка интерфейса
vcgencmd get_camera
# Должно показать: supported=1 detected=1
```

### Ошибка импорта picamera2

```bash
sudo apt update
sudo apt install -y python3-picamera2

# Проверка
python3 -c "from picamera2 import Picamera2; print('OK')"
```

### Плохое качество изображения

1. **Фокус:** OV5647 имеет фиксированный фокус, объекты должны быть на расстоянии 30+ см
2. **Освещение:** CSI камеры плохо работают в темноте
3. **Чистота линзы:** Аккуратно протрите линзу мягкой тканью
4. **Проблемы с шлейфом:**
   - Убедитесь, что шлейф полностью вставлен контактами в нужную сторону
   - Проверьте шлейф на повреждения или разрывы
   - Попробуйте другой шлейф, если доступен
   - Убедитесь, что зажим плотно защёлкнут

### Проблемы с производительностью

- Используйте меньшее разрешение для более высокого FPS
- Убедитесь, что Raspberry Pi не перегревается (проверьте температуру)
- Закройте ненужные приложения для освобождения RAM
- Рассмотрите возможность установки системы охлаждения
