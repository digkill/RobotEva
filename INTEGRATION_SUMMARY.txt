🚀 QUICK START GUIDE
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. HARDWARE SETUP
   - Power off Raspberry Pi
   - Connect camera ribbon cable to CSI port
   - Blue side of cable should face audio jack
   - Secure the black clip

2. ENABLE CAMERA INTERFACE
   sudo raspi-config
   → Interface Options → Camera → Yes
   sudo reboot

3. INSTALL DEPENDENCIES
   bash install_camera_deps.sh

4. VERIFY DETECTION
   libcamera-hello --list-cameras
   # Should show: "0 : ov5647 [2592x1944..."

5. TEST CAMERA
   python3 test_ov5647.py
   # Should create: test_ov5647_capture.jpg

6. RUN ROBOTEVA
   python3 main.py
   # Should see: "CSI камера инициализирована..."

🐛 COMMON ISSUES & SOLUTIONS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

❌ Camera not detected
   → Check ribbon cable connection
   → Run: vcgencmd get_camera (should show: detected=1)
   → Run: libcamera-hello --list-cameras
   → Enable in raspi-config: Interface Options → Camera

❌ ModuleNotFoundError: No module named 'picamera2'
   → Run: sudo apt install -y python3-picamera2

❌ ModuleNotFoundError: No module named 'cv2'
   → Run: pip3 install opencv-python
   → Or: sudo apt install python3-opencv

❌ Poor image quality
   → Keep objects 30cm+ away (OV5647 has fixed focus)
   → Ensure good lighting (CSI cameras need more light)
   → Clean lens with soft cloth
   → Check ribbon cable for damage

❌ Low FPS / Performance issues
   → Use lower resolution (640x480 @ 58fps)
   → Check temperature: vcgencmd measure_temp
   → Close unnecessary applications
   → Add cooling if needed
