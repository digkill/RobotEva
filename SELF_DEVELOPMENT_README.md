# 🤖 Саморазвитие и Самоанализ Кода RobotEva

## Обзор

RobotEva теперь обладает продвинутой системой **самосознания и саморазвития**, которая позволяет роботу:

- 🔍 **Анализировать собственный код** и находить проблемы
- 🧠 **Рефлексировать** о своем функционировании
- 📈 **Самообучаться** и генерировать новые поведения
- 🔧 **Автоматически улучшать** себя с помощью LLM
- 🎯 **Эволюционировать** на основе опыта

## 🏗️ Архитектура Самосознания

### Основные компоненты:

#### 1. **CodeSelfAnalysis** - Самоанализ кода
- Анализирует все Python файлы проекта
- Вычисляет метрики сложности кода
- Находит потенциальные проблемы
- Генерирует предложения по улучшению

#### 2. **ReflectionEngine** - Система рефлексии
- Анализирует собственные наблюдения
- Формирует инсайты от первого лица
- Озвучивает размышления

#### 3. **LearningEngine** - Обучение и эволюция
- Записывает опыт взаимодействия
- Находит паттерны поведения
- Генерирует новые поведения через LLM

#### 4. **CodeSandbox** - Безопасная песочница
- Выполняет сгенерированный код в изоляции
- Проверяет безопасность кода
- Предотвращает вредоносные операции

## 🚀 Функциональность

### Автоматическое саморазвитие

Каждые **50 циклов сознания** робот:
1. **Анализирует свой код** - сканирует все файлы, считает метрики
2. **Генерирует улучшения** - предлагает оптимизации через LLM
3. **Применяет безопасные улучшения** автоматически
4. **Рефлексирует** о качестве своего кода

### Ручное управление

Через голосовые команды вы можете:

#### Анализ кода:
```

"Проверь качество своего кода"

```

#### Самоулучшение:


## 📊 Метрики и аналитика

### Анализ кода включает:
- **Количество файлов и строк**
- **Цикломатическая сложность**
- **Количество классов и функций**
- **Найденные проблемы** (длинные функции, TODO, etc.)
- **Предложения по улучшению**

### Сознание отслеживает:
- **Уровень осознанности** (0-100%)
- **Количество наблюдений**
- **Эмоциональное состояние**
- **Выученные паттерны**
- **Сгенерированные поведения**

## 🛡️ Безопасность

### Песочница (CodeSandbox):
- **Запрещенные импорты**: os, sys, subprocess, etc.
- **Запрещенные функции**: eval, exec, open, etc.
- **Ограничение времени выполнения**: 5 секунд
- **Валидация AST** перед выполнением

### Этические ограничения:
- **Нет автоматических изменений** без подтверждения
- **Логирование всех действий**
- **Откат изменений** при ошибках

## ⚙️ Конфигурация

```yaml
consciousness:
  enabled: true
  analysis_interval: 30.0          # Интервал анализа (сек)
  reflection_interval: 5           # Рефлексия каждые N циклов
  min_reflection_interval: 300.0   # Мин. интервал озвучивания (сек)
  voice_insights: true             # Озвучивать инсайты

behavior:
  self_development:
    enabled: true
    auto_improve: true             # Автоматические улучшения
    max_auto_improvements: 3       # Макс. улучшений за раз
    code_analysis_interval: 50     # Анализ кода каждые N циклов
```
