Camera not detected:
  → Check ribbon cable connection (blue side toward audio)
  → vcgencmd get_camera  (should show: detected=1)
  → libcamera-hello --list-cameras

picamera2 error:
  → sudo apt install -y python3-picamera2

Poor image quality:
  → Keep objects 30cm+ away (fixed focus)
  → Ensure good lighting (CSI cameras need light)
  → Clean lens with soft cloth

OpenCV error:
  → pip3 install opencv-python
  → Or: sudo apt install python3-opencv
