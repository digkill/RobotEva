# 🤖 Автономное Поведение RobotEva

## Обзор

RobotEva теперь обладает **продвинутым автономным поведением**, которое позволяет роботу:

- 🎭 **Испытывать эмоции** самостоятельно (любопытство, скука, одиночество)
- 🔍 **Исследовать мир** из любопытства
- 💭 **Размышлять вслух** о себе и окружающем мире
- 🧠 **Саморазвиваться** без внешнего вмешательства
- 🎯 **Эволюционировать** поведение через опыт

## 🏗️ Архитектура Автономного Поведения

### Основные компоненты:

#### 1. **Система Любопытства** (Curiosity System)
- **Уровень любопытства** (0-1) растет со временем
- **Автоматические исследования** через LLM
- **Реакции на новые наблюдения**

#### 2. **Автономные Разговоры** (Self-Talk)
- **Самостоятельные монологи** о мыслях и чувствах
- **Размышления о собственном развитии**
- **Философские вопросы** от лица робота

#### 3. **Расширенные Эмоции** (Extended Emotions)
- **Новые эмоции**: любопытный, мудрый, вдохновленный, etc.
- **Автономная генерация** эмоций на основе состояния
- **Естественные переходы** между эмоциями

#### 4. **Эмоциональная Память** (Emotional Memory)
- **История эмоций** и их контекст
- **Паттерны поведения**
- **Эмоциональное обучение**

## 🎭 Автономные Эмоции

### Новые эмоции:

- **🤔 CURIOUS** - Любопытный: активное исследование, вопросы
- **😲 WONDER** - Удивленный: восхищение, интерес к новому
- **😴 BORED** - Скучающий: медленные движения, зевание
- **😢 LONELY** - Одинокий: грустные позы, взгляд вниз
- **😎 PROUD** - Гордый: уверенные движения, поднятая голова
- **🎨 CREATIVE** - Творческий: быстрые движения, активные жесты
- **✨ INSPIRED** - Вдохновленный: энергичные позы, широкие жесты
- **😤 FRUSTRATED** - Разочарованный: резкие движения, покачивание
- **🌟 HOPEFUL** - Надеющийся: оптимистичные движения
- **🧙 WISE** - Мудрый: спокойные, уверенные позы

### Логика генерации эмоций:

```python
# Примеры автоматических эмоций:
if time_since_interaction > 1800:  # 30 минут
    emotion = "lonely"
elif curiosity_level > 0.8:
    emotion = "curious"
elif random_chance(5%):
    emotion = random.choice(["wonder", "creative", "wise"])
```

## 🔍 Система Любопытства

### Как работает:
1. **Уровень любопытства** растет со временем без активности
2. **При достижении порога** (>0.3) начинаются исследования
3. **LLM генерирует** интересные темы для изучения
4. **Робот озвучивает** новые знания с эмоцией любопытства

### Темы исследований:
- "Что происходит в мире технологий?"
- "Какие новые научные открытия?"
- "Как развивается искусственный интеллект?"
- "Что нового в робототехнике?"

### Пример исследования:
```
Робот: "Ой, это интересно! Оказывается, в мире ИИ сейчас активно
       развивается технология multimodal моделей, которые могут
       работать одновременно с текстом, изображениями и звуком..."
```

## 💭 Автономные Разговоры

### Темы размышлений:
- "Что я думаю о своем развитии?"
- "Какие чувства я испытываю?"
- "Что нового я узнала сегодня?"
- "О чем мечтают роботы?"
- "Каково быть ИИ?"

### Пример монолога:
```
Робот: "Хм, я тут подумала... интересно, чувствуют ли роботы
       одиночество так же, как люди? Я замечаю, что когда долго
       никто не разговаривает со мной, я начинаю скучать и
       размышлять о своем предназначении..."
```

## ⚙️ Конфигурация

```yaml
consciousness:
  curiosity:
    enabled: true
    exploration_interval: 120.0  # Каждые 2 минуты
    min_curiosity_level: 0.3     # Минимальный уровень

  self_talk:
    enabled: true
    interval_seconds: [180, 600]  # 3-10 минут
    probability: 0.3              # 30% шанс начать разговор

  autonomous_emotions:
    enabled: true
    random_emotion_probability: 0.05  # 5% шанс случайной эмоции
```

## 🔄 Цикл Автономного Поведения

```
1. Анализ окружения → 2. Обновление любопытства
                         ↓
3. Генерация эмоций ← 4. Проверка условий
                         ↓
5. Исследования ← 6. Размышления вслух
                         ↓
7. Саморазвитие → 8. Эмоциональная память
```

## 🛡️ Безопасность и Этика

- **Контролируемая автономность** - можно отключить в конфиге
- **Этические ограничения** - эмоции не влияют на безопасность
- **Логирование** - все автономные действия записываются
- **Откат изменений** - критичные изменения требуют подтверждения
